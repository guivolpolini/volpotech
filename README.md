# VolpoTech — Presença Digital com Propósito 🚀

Bem-vindo ao repositório oficial da **VolpoTech**. 

Aqui desenvolvemos experiências digitais modernas, velozes e focadas no que realmente importa: **ajudar comércios e empresas a serem encontrados na internet, transmitirem credibilidade e fecharem mais negócios.**

---

## ✨ Sobre a VolpoTech

A VolpoTech nasceu para simplificar a vida de quem empreende. Sabemos que ter um site bonito é só o começo; o projeto precisa carregar rápido no celular, ser intuitivo, ranquear no Google e facilitar o contato direto pelo WhatsApp.

### O que entregamos na plataforma:
- **Design Exclusivo & Moderno:** Interface escura (*dark mode*), visual limpo e tipografia pensada para leitura confortável.
- **100% Responsivo:** Experiência fluida tanto na tela do smartphone quanto no computador.
- **Orçamento Sob Medida:** Apresentação clara de soluções, conectando o cliente diretamente com nosso time via WhatsApp para desenhar propostas personalizadas.
- **Placa Google com NFC & QR Code:** Solução física inovadora para balcões, facilitando a coleta de avaliações 5 estrelas no Google em segundos.
- **Painel Administrativo Próprio (`/admin`):** Gerenciamento completo de textos, portfólio, serviços, leads recebidos e planos sem precisar tocar em uma linha de código.

---

## 🛠️ Tecnologias Utilizadas

Construído com uma stack leve, moderna e de alto desempenho:

- **[React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/):** Base sólida, tipada e com componentes reutilizáveis.
- **[Vite](https://vitejs.dev/):** Ambiente de desenvolvimento ultrarrápido e empacotamento otimizado.
- **[Tailwind CSS](https://tailwindcss.com/):** Estilização utilitária refinada com efeitos de blur e gradientes sutis.
- **[Lucide React](https://lucide.dev/):** Pacote de ícones minimalistas e consistentes.
- **[React Router](https://reactrouter.com/):** Navegação SPA instantânea entre páginas.

## 💻 Como Rodar o Projeto Localmente

Se você for rodar ou contribuir com o projeto, siga o passo a passo:

### 1. Clonar o repositório
```bash
git clone https://github.com/guivolpolini/volpotech.git
cd volpotech
```

### 2. Instalar as dependências
```bash
npm install
```

### 3. Iniciar o ambiente de desenvolvimento
```bash
npm run dev
```
O projeto estará disponível no seu navegador em `http://localhost:5173`.

### 4. Gerar build de produção
```bash
npm run build
```
